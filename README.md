# Northwind Ops dashboard

Internal operations overview: headline KPIs, six-month revenue, recent team activity and the latest invoices.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Build

```bash
npm run build
npm run preview
```

Stack: React 18, TypeScript, Vite. Styles are plain CSS in `src/styles/`.
